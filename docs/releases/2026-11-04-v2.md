# v2 发布说明（2026-11-04）

许可证：MIT。快速开始见 [README.md](../../README.md)。开发进度以 [GitHub Issues](https://github.com/wwq0327/mistake-loop/issues) 为准，编号映射见 [issue-map.md](../github/issue-map.md)。

## 已完成

- **结构**：从「一次提交一整张表」改为「收件 → 加工」两段，中间用草稿表承接。六页按动作组织：工作台 / 识别收件箱 / 题目详情 / 打印 / 题库 / 设置。
- **AI 图片识别**：OpenAI 兼容视觉接口可插拔，一张照片切成多条草稿，低置信度留空不猜；单并发 worker、每日配额、六类失败降级。**只产草稿，教师逐题确认才写 `mistakes(status='new')`**，重复确认幂等。默认 `AI_ENABLED=0`，设置页有进程内暂停开关。
- **数据层**：9 张表，`migrateV2` 幂等升级；已有 v1 库用 `npm run migrate:v2` 先备份再迁移；新克隆启动自动建库。原图与压缩图分层保存，与错题强关联。
- **设计系统**：CSS 分 tokens / base / components / layout / print 五层，三档响应式，深色与 reduced-motion；UI 静态规范纳入 `npm run check`。
- **交付验证**：本版覆盖 P0–P10 共 39 个 Issue；v1 的 28 个测试一个未改，全量 245 个用例全绿；CI 跑 Node 22 与 26 双版本矩阵；B1–B12 验收 **11 PASS / 0 FAIL / 1 待判断**，逐项数字见 [验收报告](../audits/2026-11-04-v2-acceptance.md)。
- **教学法红线守护**：AI 不判掌握、不生成掌握证据、不替学生说结论、不自动写库、不改写历史复习记录；学生版打印永不返回答案与引导提示；未确认草稿不进题库、今日复习、打印与统计。

## 未验证

以下四项**没有**验证过，页面做完、测试通过、命令成功都不能代替这一层验收：

1. 真机 NAS 上的容器构建与拉起：镜像已在 CI 里验证可构建（amd64 + arm64、Node 26、非 root 运行、/health 回读通过），但真机 NAS 拉起、卷属主与重启自愈仍未验证。
2. 真实手机 / 平板的系统相机调起与浏览器兼容。
3. 浏览器打印预览的实际分页效果与 A4 出纸。
4. 两周真实试运行与学情判断（无提醒时每周主动使用约 3 次）。

**B11 视觉一致性**同样待使用者判断，不由开发自评：静态视觉稿 6 屏见 [ui-preview.html](../design/ui-preview.html)，实际六页为 `/`、`/inbox`、`/mistake/:id`、`/print`、`/library`、`/settings`。

其他已知限制：无账号与权限体系、无公网暴露（代码侧）、无学生在线答题与家长端、无自动判分与变式免审核；英语错因子类型留空；旧 19 题是三下、教材地图是四上，标记「待补教材定位」不自动猜。

## 许可证与数据边界

- 代码 MIT，见 [LICENSE](../../LICENSE)。仓库不含、也不应该含任何真实学生数据与照片。
- `data/`（数据库、图片、备份）已 gitignore，**不进版本库、不上传 GitHub**；由使用者自行备份。
- 学生端全纸质，系统不存学生账号、不做在线答题、不做打卡排名积分。
- AI 图片识别**默认关闭**；启用后题目照片会发往使用者自行配置的服务商，可能含未成年人笔迹。不配置也能完整使用全部非 AI 功能；未启用或识别失败一律退回可手填空白草稿，等价路径不打折。
- 密钥只走容器环境变量，不进代码、不进日志、不进 Issue 正文、不建 `.env`。隐私与漏洞报告见 [SECURITY.md](../../SECURITY.md)。
- 旧库 `mistake-wiki/` 全程只读，不写入、不修改、不删除、不移动。
- 不做路由器公网端口映射；校外访问走 Tailscale，属使用者侧配置。

