批改账簿错 题 账 簿

这不是一个 SaaS 仪表盘，是教师桌上一本摊开的错题账簿。暖纸、墨字、账格横线与序号；朱红是唯一的强调色，像红笔圈出该改的那一题。用于 B11 视觉一致性对照，也是六页 CSS 令牌的命名来源。

一、色板

纸与墨定调，深墨蓝只管结构，青灰/赭只保留状态语义。朱红不铺面，只出现在当前态、圈题框、序号与起首批改章。

纸页--color-surface / #fffdf7

深墨蓝--color-primary / #1f3a4d

青灰--color-teal / 已掌握

二、活字与纸面

标题与数字用衬线活字栈（Iowan Old Style / Baskerville / Songti SC / STSong / SimSun / Georgia），中文正文保留无衬线栈保小字号可读性。全部是本机字体回退，不发外网、不引字体文件、不加构建链。

今天该做什么

15 / 19

衬线数字有字形对比，不像等宽无衬线那样把每个数字都喊成一样响。正文仍是 16px 无衬线，长时间看不累。

账格横线只在空态与答题区出现，31px 一行，极淡。纸纹是两层 7px 网点，不是噪点图片。打印时两者都关掉，答题线由真实 border 提供。

四、深色与打印

场景处理
系统深色夜灯下的账本：墨底纸字，朱红提亮为 #e0785f，纸纹更轻；书脊与当前态仍可辨。
A4 出纸强制浅色，关闭纸纹与账格背景，题卡朱红粗边退回细墨线；一题一卡、不跨页断题，学生版字段白名单不变。
动效只有一次编排好的页面载入（纸页按序落桌），CSS-only；prefers-reduced-motion 下自动关闭。
硬约束44px 触控下限、label[for]、状态标签颜色加文字、六组令牌命名、375/768/1440 三档断点、零框架零构建链、只有 express 一个依赖。

五、这不是什么

  • 不做 紫色渐变、玻璃拟态、平均分布等宽卡片、全圆角胶囊、云朵阴影。
  • 不做 Inter / Roboto / Arial 当展示字体，不引字体 CDN，不引图片资源。
  • 红线 学生版打印永不返回答案与引导提示；AI 只产草稿，教师确认才入库；不做排名积分打卡。
静态视觉稿，自包含零外链，不是成品页面。实际六页在 /、/inbox、/mistake/:id、/print、/library、/settings；B11 视觉一致性由使用者对照判断，不由开发自评通过。
