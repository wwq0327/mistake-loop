# mistake-loop

一个一直开着的错题网页。老师把错题拍进去，系统每天自己算出「今天该复习哪些题」，老师打印成 A4 纸给学生做，把结果记回来，直到有真实证据证明学生真会了才过关。

学生不碰系统，全部在纸上做题。家长不是必需环节。

---

## 一、最快跑起来（本机）

```bash
cd /Users/walt/codes/my/mistake-loop
npm install          # 已装好，可跳过
npm run import:legacy # 只读导入旧库，只需跑一次；本项目已经跑过
npm run dev
```

浏览器打开 `http://localhost:8080`。手机或平板在同一局域网里打开 `http://<本机或NAS的IP>:8080`。

> 本项目当前 `data/mistakes.db` 已经含旧库 19 道错题、6 道变式、19 张图片、25 个教材单元节点。直接 `npm run dev` 就能看到「今日复习」里那 15 道逾期题——这正是设计目的：把它们捞回来。

## 二、三个页面

| 地址 | 干什么 |
| --- | --- |
| `/index.html` | 首页。看实时统计、审核变式、记录今天做对/做错、补掌握证据 |
| `/capture.html` | 录入。拍照、填题干、写支架式诊断、顺手补三层变式；保存后保留科目可连着录 |
| `/print.html` | 勾选题目生成 A4 学生版练习纸，点「打印」出纸 |

学生版打印页**不含答案、不含引导提示**，一题一张卡片、不跨页断开。答案只在系统详情页（教师侧）。

## 三、每天怎么用

1. 改作业看到典型错题 → 手机打开「录入」，拍照、填题干、保存。可以连着录。
2. 在录入页写「定位问题」（一次只问学生一个点）和「学生自己说出的关键结论」。**结论没填，系统不许推进到纠错中。**
3. 顺手补三道变式：换数字、换角度、换场景。提交后到首页「待审核变式」逐条点通过/未通过——**没审核不上打印纸**。
4. 首页「今日复习」是系统每天 00:05 自己算出来的，不用你记。
5. 到「打印」页勾题，出 A4 纸给学生。
6. 收回来在首页点「做对 / 做错」。做对按 1、3、7、30 天往后排；做错打回诊断、轮次归零。**忘了几个月不惩罚、不从头开始。**
7. 做对第 4 轮还不算会，得再补一条掌握证据（复述 / 同结构变式 / 间隔提取 / 说出检查方法 / 讲给别人听），才标「已掌握」。

## 四、数据放在哪

| 路径 | 内容 |
| --- | --- |
| `data/mistakes.db` | 全部记录（SQLite，WAL 模式） |
| `data/images/` | 手机拍的照片 |
| `data/images/legacy/` | 旧库只读复制过来的 19 张图片 |
| `data/backups/` | 备份快照（运行 `npm run backup` 后生成） |

`data/` 已 gitignore，不进版本库。**数据库和图片要另外备份**，git 不管它们。

```bash
npm run backup                              # 备份并自动做一次临时目录恢复演练
node scripts/backup.mjs --restore <备份目录>  # 单独校验某个备份
```

备份不会删历史备份，恢复演练只在临时目录做，绝不覆盖现有数据。

## 六、NAS 部署

```bash
mkdir -p data
sudo chown -R 1000:1000 data   # 只需执行一次；容器内以非 root 用户运行，需要写权限
docker compose up -d --build
```

- 不在路由器做公网端口映射。校外访问走 Tailscale，属你自己侧的配置。
- 镜像不写死 CPU 架构，由 NAS 本机决定（本轮未确认 amd64 / arm64）。
- 密钥走环境变量，第一版不接真实 AI，不建 `.env`。

## 八、已知限制与需要你实机确认的事

以下四项**没有**在本次交付里验证，别当成已完成：

1. 真实 NAS 容器构建与 arm64 / amd64 镜像（架构未确认，只做了本机 `npm run dev` 与配置检查）。
2. 真实手机 / 平板的系统相机调起与浏览器兼容（代码用 `<input capture>` 绕开 HTTPS 限制，但需实机拍照确认）。
3. 浏览器打印预览的分页效果（A4 CSS 已写，需你实际打印预览看一眼）。
4. 两周真实试运行与学情判断（这是产品验收，不是代码验收；页面做完、测试通过都不能代替）。

其他已知限制：

- 本机是 Node 22.22.2，`node:sqlite` 在此版本是实验特性，运行会输出一条 `ExperimentalWarning`；生产容器固定 Node 26 LTS，无此问题。
- 第一版没有账号、没有公网、没有学生在线答题、没有家长端、没有 OCR 自动切题、没有 AI 实时讲题。
- 英语错因子类型留空，等真实英语错题积累后再补；不硬套数学结构。
- 旧 19 题是三年级下册，教材地图是四年级上册，两者挂不上，因此这 19 题标记为「待补教材定位」，不会自动猜。
- 两层验收的区别见 `docs/requirements/PRD.md` 第九节。
